# 若依后端部署与接口

## 当前可用与待配置

本机 Java / MySQL / Redis 已联调。没有公网服务器、HTTPS域名和微信AppID；尚未进行公网或微信真机验证。站点Worker运行时不能运行Java，所以此前Worker托管方案未继续发布。

本地后台地址5176，小程序5173，Java8080，专用Redis6388；独立MySQL数据库maoyi_ruoyi，专用用户maoyi_app。没有修改电脑原有的其他业务数据库和Redis6379数据。

## 账号和权限

管理员在若依“用户管理”新增账号并启用，在“角色管理”分配：

- 工艺员工（maoyi_employee）：小程序登录、自己的工艺保存、提交和分享。
- 工艺主管（maoyi_supervisor）：后台工艺查看、审批、分享查看与撤销。
- 工艺顾客（maoyi_customer）：微信新账号默认角色，与其他顾客隔离。
- 超级管理员：若依原有管理员，拥有后台全部权限。

小程序员工登录不增加原版没有的图形验证码输入，使用密码失败锁定与服务端限流；管理后台保留若依原有验证码流程。密码使用若依 BCrypt，令牌使用若依 JWT + Redis，账号与权限变更在业务接口实时校验。管理员创建“停用”账号后，可在审核完成时启用；小程序不会允许停用账号登录。

## 数据库

以下路径以`maoyi-app`为当前目录。新环境按顺序执行 `../maoyi-backend/sql/ry_20261117.sql`、`../maoyi-backend/sql/quartz.sql`、`../maoyi-backend/sql/maoyi/001_business.sql`。前两份是官方初始化脚本，包含DROP语句，只能在新建专用数据库执行，不能对有业务数据的旧库重复执行。

业务表：maoyi_member、maoyi_craft、maoyi_audit、maoyi_share、maoyi_chart。工艺状态：draft → pending → approved/rejected；驳回后可以修改为draft并再次提交。版本号用于防止覆盖更新，审批结果与审计记录在同一数据库事务中提交。

## Docker部署

1. 准备Linux服务器、Docker Compose插件、两个HTTPS域名（小程序分享域名、管理后台域名）。
2. 本地先构建Java，以准备密码散列依赖。执行 `npm run prepare:deploy -- https://小程序分享域名`。
3. `.secrets/deploy.env` 保存随机数据库密码、JWT密钥和PUBLIC_ORIGIN；`.secrets/deploy-init.sql` 替换官方默认管理员密码并停用演示账号；账号单独保存在 `.secrets/云端管理员账号.txt`。这些文件不在源码压缩包内，需通过自己的安全方式复制到服务器。`.secrets/` 目录保持700，env和账号文件保持600；仅含BCrypt哈希的初始化SQL保持644，供容器内mysql用户读取。
4. 将三个同级工程及私有配置复制到服务器，并执行`cp deploy/workspace.dockerignore ../.dockerignore`准备共同父目录的构建白名单后，在`maoyi-app`目录运行 `docker compose --env-file .secrets/deploy.env -f deploy/compose.yml up -d --build`。
5. HTTPS反向代理：小程序域名 → 本机127.0.0.1:8090；管理域名 → 本机127.0.0.1:8091。前者 `/api/`、后者 `/prod-api/` 已在容器Nginx内转发Java。MySQL、Redis、Java不直接映射公网端口。
6. 若依管理员在“用户管理”创建自己的工艺员工与主管。备份MySQL数据卷、上传文件卷及服务器密钥；不要运行 `down -v` 删除数据卷。

Compose配置校验通过；镜像构建和Docker启动在当前环境未验证（缺少运行中的Docker引擎）。本机运行流程独立于Docker，已经通过联调。

## 微信配置

注册自己的微信小程序，取得AppID/AppSecret；AppSecret放服务器 `WECHAT_APP_SECRET`，AppID放服务器 `WECHAT_APP_ID`。添加分享域名到微信 request 合法域名，重启Java，再用正式AppID打包：

```sh
WECHAT_APP_ID=wx你的AppID VITE_API_BASE_URL=https://小程序分享域名/api npm run build:wechat-release
```

开发者工具导入dist/build/mp-weixin。编译脚本只在构建期间写入公开AppID，随后恢复源文件；不会把AppSecret写入客户端。`wx.login` 成功得到code后，Java调用微信官方 `jscode2session`，只使用OpenID建号，不保存session_key。微信新用户固定为顾客角色；不能通过客户端指定角色。

## 接口

小程序 `/api/auth/login`、`/auth/me`、`/auth/logout`；`/crafts`、`/crafts/{id}`、`/crafts/{id}/submit`；`/shares`、公开GET `/shares/{code}`；`/charts`。除健康、登录和读取分享外都需要Bearer令牌。

管理端 `/maoyi/craft/list`、`/craft/{id}`、POST `/craft/{id}/review`；`/share/list`、PUT `/share/{id}/revoke`。使用若依按钮权限控制，服务端再次校验。管理端和小程序直接使用同一数据库，无复制同步延迟。

分享链接使用256位随机令牌，数据库仅存SHA256摘要；快照只包含工艺内容，不带账号和审批记录。七天后失效，后台可撤销；接收页由H5承载，二维码就是同一HTTPS链接。
