## 验证与剩余边界

- 本文记录原版读取依据与实现范围，当前逐动作测试结果以唯一台账 [qa/ledger.json](qa/ledger.json) 为准。历史读取截图、自动化、H5、微信预览构建和真机测试分别记录，不互相替代。
- 前轮曾用 414 × 780 逻辑尺寸核对桌面小程序布局，不表示本轮全部宽度和页面已回归。当前真实 Chrome 320 宽仅完成部分游客表单；其他窄屏与真机覆盖仍看台账中的未完成项。字体、emoji、微信胶囊的宿主渲染存在平台差异；H5 使用外观占位，微信版由宿主绘制。
- 原版结构图按可见图形重绘，不是原软件导出的资源。后续视频需求使用 `video-v1` 统一引擎，依据实际尺寸生成衣片轮廓与针行标注，不再用原示意图或固定比例代替。
- 旧口径样例仅作为历史兼容依据，不能替代视频平铺胸宽算例。规则来源、已确认关系和扩展规则限制见 [计算视频核对记录](references/calculation-video/review.json)；视频未给出所有款式的完整算法，自动化针行守恒不能替代实际织样。
- 当前尺寸字段全集为 21 项，按款式和袖型显示：默认套头长袖 19 项、背心 13 项、开衫长袖 21 项。包含实际袖口宽及开衫门襟宽 / 长；表单标题使用适用字段数，不沿用早期固定数量。
- 顾客账号无法读取主管 / 超级管理员页面；未臆造这些页面。
- 未修改原版账号数据验证写入。本项目工艺、审批、图纸保存已经接入若依 Java / MySQL；接口与数据库证据不代表用户端登录后保存、重进、导出、分享发起的真实页面链都已验收。
- 原版导出最终图片未核对；当前导出基于工艺结构图，实际下载及设备相册分支尚须按台账执行。
- 员工登录、多人审批和匿名分享接口已有本机联调证据；公网部署需要服务器和 HTTPS 域名，真实微信登录需要自己的 AppID / AppSecret。模型当前复刻的是原版参数控件、初始空态和生成后无匹配空态。真实资产及匹配契约未获得，资源检索与加载器也尚未实现，不能当作已实现真实 2D / 3D 模型生成；这一能力缺口继续保留在 U054，不能仅提供素材就宣称可用。
- 本轮 H5 与微信预览的 R12 候选构建记录为 `.data/qa/user-evidence/h5-r12-build.txt`、`weixin-r12-build.txt`，候选产物哈希在 `r12-drawing-builds.json`；是否已冻结发布和真实复测仍以台账为准。完整 `npm test` 输出为 `core-full-npm-test-r12.txt`，测试数量读取该批次日志汇总，不使用前轮固定数量。微信开发者工具、真实设备及真实渠道仍未完成验收。

因此本次交付应称为“根据已读取的游客和顾客页面重建的可运行版本”，不能称为原软件全部角色、服务端和所有算法的完整一比一复刻。
